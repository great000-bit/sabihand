# Sabihand

Find a verified artisan near you, see the price range, pay safely. A location-based artisan marketplace for Nigeria
(plumbers, electricians, tailors, carpenters first), built for the Cowrywise Ambassadors Innovation Challenge 2026.

**Status: prototype in demo mode.** Sample artisans and a pretend payment; nothing is real money or a real person.

- Plan, defaults and open decisions: [docs/BUILD_PLAN.md](docs/BUILD_PLAN.md)
- Database schema (not yet applied): [supabase/migrations/0001_init.sql](supabase/migrations/0001_init.sql)
- Next.js 16 conventions for this repo: [AGENTS.md](AGENTS.md)
